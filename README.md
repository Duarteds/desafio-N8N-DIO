Criação de um prompt de IA Generativa pra criação de uma automação na ferramenta N8N. Este projeto define a criação de um prompt
para acompanhar novos tickets de atendimento em um CRM e notificar a equipe de suporte. 

Atue como um especialista em N8N.

Quero criar uma automação no N8N para Acompanhar a criação de tickets de atendimento no CRM.

Público ou responsável:
Equipe de Suporte.

Resultado esperado:
Salvar informações em uma planilha e enviar uma notificação para o time de suporte.

Ferramentas envolvidas:
Sistema CRM, Google Sheets e Gmail.

Fluxo desejado:
1. Receber notificação de criação de tickets.
2. Registrar os dados na planilha.
3. Enviar um e-mail de confirmação.

Regras importantes:
Ignorar registros sem e-mail válido e sem descrição do problema.
